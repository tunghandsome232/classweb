Đồng Bộ Cơ Sở Dữ Liệu Đám Mây (Cloud Database)

Dùng Google Firebase Realtime Database 100% Miễn Phí Vĩnh Viễn

Trạng Thái Đồng Bộ: Chưa kết nối (Đang lưu trên trình duyệt của máy)
📖 Hướng Dẫn Lấy Database URL Miễn Phí Trong 2 Phút:
  1. Truy cập console.firebase.google.com (Đăng nhập bằng Gmail miễn phí).
  2. Bấm "Thêm dự án" (Add project) → Đặt tên (VD: a8k59yt) → Tiếp tục cho đến khi hoàn tất.
  3. Ở menu bên trái chọn Build → Realtime Database → Bấm "Create Database".
  4. Chọn vị trí (Singapore hoặc US) → Chọn chế độ "Start in test mode" (Bắt đầu ở chế độ thử nghiệm: .read = true, .write = true) → Bấm Enable.
  5. Sao chép đường link Realtime Database (dạng https://ten-du-an-default-rtdb.firebaseio.com/ hoặc https://...firebasedatabase.app/) dán vào ô bên dưới!

💡 Chỉ cần dán link Database URL là xong! Hệ thống sẽ tự động khởi tạo kết nối WebSockets thời gian thực.

Thao Tác Đồng Bộ Thủ Công:

* Khi đã bật Đám Mây, bất kỳ hành động nào (Đăng ký tài khoản, chấm thi đua, sửa TKB) sẽ TỰ ĐỘNG đồng bộ tức thì không cần bấm thủ công.
